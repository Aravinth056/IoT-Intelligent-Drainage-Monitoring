# IoT Intelligent Drainage Monitoring System

An IoT-based drainage monitoring system designed to monitor water level, water flow, rainfall, blockage, and flood-risk conditions in real time.

## Project Objective

The objective is to develop a low-cost system for continuous drainage monitoring and early detection of abnormal conditions.

## Key Features

- Real-time water-level monitoring
- Water-flow monitoring
- Rainfall detection
- Blockage detection
- Overflow warning
- Flood-risk monitoring
- LCD display
- Wi-Fi-based web dashboard
- Live monitoring graph
- CSV data download

## Hardware

- ESP8266 NodeMCU
- HC-SR04 Ultrasonic Sensor
- Water Flow Sensor
- Rain Sensor
- 16×2 LCD Display
- 5V Power Supply
- Drainage Prototype

## Software

- ESP8266 programming
- IoT monitoring dashboard
- Wi-Fi communication
- Real-time data monitoring
- CSV data logging

## Project Structure

- `images/` – Prototype and project photographs
- `CAD/` – 3D CAD model and design views
- `hardware/` – Hardware components and specifications
- `software/` – Program and software-related files
- `docs/` – Project documentation
- `results/` – Testing and performance results

## Results

The prototype was tested for water-level monitoring, water-flow detection, rainfall detection, blockage detection, overflow detection, and dashboard monitoring. The report records successful test results for these functions. 

## Applications

- Urban drainage monitoring
- Drainage blockage detection
- Overflow monitoring
- Flood-risk monitoring
- Smart city applications
