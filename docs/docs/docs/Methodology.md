# Methodology

## 📌 Overview

The proposed system follows a sensor-based monitoring approach to continuously observe drainage conditions and provide early warnings for blockage and flood risks.

## 🔄 System Methodology

```text
Sensor Data Collection
        ↓
ESP8266 Processing
        ↓
Threshold Comparison
        ↓
Drainage Status Detection
        ↓
Wi-Fi Communication
        ↓
Web Dashboard
        ↓
Warning + Data Logging
