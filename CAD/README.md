# CAD Design

## 📌 Overview

This folder contains the CAD design and modelling documentation of the **IoT-Enabled Intelligent Sewer Monitoring and Flood Risk Early Warning System**.

The CAD model represents the physical arrangement of the monitoring system and its major components.

---

## 📐 CAD Design

The CAD documentation can be used to represent:

- Overall system assembly
- Monitoring unit
- Sensor arrangement
- Electronic component arrangement
- Enclosure / protective structure
- Mounting arrangement

---

## 👁️ CAD Views

The following CAD views can be included:

- Isometric View
- Front View
- Top View
- Side View
- Sectional View
- Overall Assembly View
