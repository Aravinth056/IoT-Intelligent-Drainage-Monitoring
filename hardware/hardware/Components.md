# Hardware Components

## 1. ESP8266 NodeMCU

- Supply Voltage: 3.3V
- GPIO Pins: 17
- Wi-Fi communication
- Main controller of the system
- Processes sensor data and sends information to the web dashboard

## 2. HC-SR04 Ultrasonic Sensor

- Supply Voltage: 5V
- Measures the distance between the sensor and water surface
- Used to determine the water level
- Mounted above the drainage channel

## 3. G1/2" Hall-Effect Water Flow Sensor

- Supply Voltage: 5V
- Pulse-output type
- Measures water flow rate
- Helps identify reduced or abnormal water flow

## 4. Rain Sensor

- Operating Voltage: 3.3–5V
- Detects rainfall
- Provides analog/digital output
- Used for rain-status monitoring

## 5. 16×2 I2C LCD

- Supply Voltage: 5V
- 16 characters × 2 lines
- I2C communication
- Displays water level, flow status, rain status and drainage condition

## 6. Water Level Sensor Module

- Operating Voltage: 3.3–5V
- Provides additional water-level information
- Used during prototype monitoring and testing

## 7. Regulated DC Power Supply

- Output Voltage: 5V
- Provides regulated power to the electronic system

## 8. Drainage Prototype Channel

- Compact laboratory-scale drainage channel
- Provides the test environment for water-level and flow monitoring
- Designed to represent a small drainage section

## 9. Protective Sensor Enclosure

- Protects electronic components from water exposure
- Provides a safer arrangement for the sensors and control electronics

## 10. Software Monitoring Dashboard

- Web-based IoT monitoring interface
- Displays live sensor data
- Shows drainage status and warnings
- Provides graphs and data logging
- Supports CSV data download
